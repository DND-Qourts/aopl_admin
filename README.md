# ALL-OUT Pickleball League — Admin Portal

Git-ready package for the latest ALL-OUT Admin Portal build.

## Deploy on GitHub Pages
1. Upload the contents of this package to the repository root.
2. Keep `index.html` in the root.
3. In GitHub: Settings → Pages.
4. Deploy from the main branch / root.

## Current build
Includes the registration verification interface with:
- team registration review
- individual DUPR ID and rating display
- team total DUPR / division eligibility
- registration verification checklist
- payment approval workflow UI
- reports and drill-down admin interface

This is the current standalone front-end build packaged for Git deployment.
