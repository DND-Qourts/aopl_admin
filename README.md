# ALL-OUT Pickleball League — Admin Portal

Static GitHub Pages-ready admin prototype with sample data.

## Deploy
1. Create a GitHub repository.
2. Upload all files in this package to the repository root.
3. Enable GitHub Pages from the main branch/root.
4. Open the generated Pages URL.

## Included
- Dashboard and registration queue
- Registration Requests
- 24-hour Payment Window
- Payment Overdue workflow
- Confirmed Teams
- Reports with drill-down
- Financial report first
- Audit/Settings/Trash scaffolding
- Sample team/player/payment data embedded in the prototype
- CSV export

This package is a front-end prototype. Sample data is local/demo data and is not connected to Supabase yet.
